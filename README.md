# ⚽ Penalty Shootout

An arcade-style football penalty shootout that runs in the browser. It is a single HTML file with no build step. Play against the computer, share one screen, or play online with friends.

## Features

- **6-zone goal:** the shooter picks where to aim and the keeper picks where to dive. The same zone is a save and a different zone is a goal.
- **Realistic keeper dives:** side dives, a jump for top-middle and a squat for low-middle.
- **Game modes:**
  - **Play vs AI:** Rookie, Pro or Legend. The AI learns your habits.
  - **Local 1v1:** two players on one screen with hidden picks.
  - **Online rooms:** 1v1 or 2v2 with a room code and invite link.
- **Rock-paper-scissors toss:** the winner chooses whether to shoot or keep first.
- **7-second timer:** if time runs out, your highlighted zone (or a random one) is used.
- **Kit editor:** customize shirt, pattern, shorts, number, gloves, skin and hair for both the shooter and the keeper.
- **Sudden death:** tied matches go to sudden death, and a match ends early once one side can't be caught.

## Controls

| Action | Keys |
| --- | --- |
| Pick a zone | `1`–`6` |
| Move selection | Arrow keys |
| Lock in | `Enter` |
| Speed up a kick | `Space` |
| Local Player 2 | Numpad `1`–`6` or `A S D F G H` |

## Run it

Open `index.html` in a browser.
